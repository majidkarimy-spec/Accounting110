# حسابداری آرمان پلیمر (Capacitor / Android)

- فایل برنامه: `www/index.html` (برای به‌روزرسانی فقط همین فایل را عوض کنید)
- هر بار که روی GitHub پوش کنید، تب Actions یک APK می‌سازد: آخرین اجرا ← Artifacts ← arman-accounting-apk
- افزونه‌ها: app (دکمه‌ی برگشت و خروج)، filesystem (ذخیره‌ی فایل)، share (ارسال)، native-biometric (اثر انگشت)
- فایل debug.keystore را حذف نکنید؛ با آن هر APK جدید روی نسخه‌ی قبلی نصب می‌شود.
- قبل از هر به‌روزرسانی از برنامه (تب «ذخیره») پشتیبان بگیرید.
